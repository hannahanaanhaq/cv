# Hanna Hanaan — Structural Engineer CV

Personal CV website built with HTML/CSS, published via GitHub Pages.

**Live site:** https://hannahanaan.github.io/cv

## Setup

1. Push this folder to a GitHub repository named `cv`
2. Go to **Settings → Pages → Source → Deploy from branch → main → / (root)**
3. Your CV will be live at `https://YOUR-USERNAME.github.io/cv`

## Updating Content

Edit `index.html` to update your personal details, experience, education, and skills.
